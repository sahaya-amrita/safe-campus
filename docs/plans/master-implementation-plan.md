## 2. Decisions needed before shared interfaces change

1. **Identity: Supabase Auth or the existing JWT.** Proposal: adopt Supabase Auth.
   - The API verifies the Supabase JWT (JWKS) and keeps roles in our own `user_roles` table, changed only by the server.
   - Migrate the four demo accounts and delete `/auth/demo-login` in production.
   - Guests use Supabase anonymous sign-in. The project owner must enable it.
2. **Database: Supabase Postgres as the only database.** Proposal: run the existing migrations 001–003 on Supabase via a server-side connection string. Add RLS to every table exposed through the Data API, or keep them unexposed (API-only access); choose one per table.
3. **Report contract v2.** Adds:
   - `location_method` (`GPS | MANUAL | QR_MARKER`), `latitude`, `longitude`, `accuracy_m`, and a required `floor_id` when a building is known;
   - a category enum (`FIRE_SMOKE | MEDICAL | PERSONAL_SAFETY | OTHER`);
   - an attachment lifecycle (`PENDING_UPLOAD → STORED → ATTACHED`, or `REJECTED`).

   Codex 1 publishes it; Claude Code 1 and 2 build against it.

4. **Maps direction.** Remove the 3D view and stop drawing computed routes on unverified geometry. Show risk/alert/blocked areas, report markers and "Navigation unavailable: no verified route data". Build A* (with a Dijkstra baseline) over an approved graph format, ready for real data.

## 4. What needs the project owner (not code)

- **Rotate the Groq key.** It was pasted into a chat transcript. Put the new one only in `services/api/.env` and the host's secret settings.
- **Enable anonymous sign-ins** in Supabase (Authentication → Sign In / Providers), if guests use Supabase anonymous auth.
- **Provide server credentials privately:** the Supabase database connection string and a secret (server) key. Put them in `services/api/.env` on the developer machine and in host secrets, **never in chat or Git**.
- **Institutional approvals:** verified contacts, approved instruction packs, building/floor geometry and routes, ERT acknowledgement timers, and a named reviewer for Tom's help text.

- Nothing is deployed yet, and no second device has accessed the app.
